# Scalable Microservices Architecture with ECS and Fargate

## 📌 Description
Containerized microservices deployed using ECS without managing servers.

## 🛠 Services Used
- ECS
- Fargate
- ECR
- ALB

## ⚙️ Workflow
1. Docker images stored in ECR
2. ECS runs containers
3. Fargate handles infrastructure
