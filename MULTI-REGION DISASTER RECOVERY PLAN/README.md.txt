# Multi-Region Disaster Recovery Plan

## 📌 Description
Setup for failover between regions to ensure high availability.

## 🛠 Services Used
- Route 53
- S3 Cross-Region Replication
- EC2

## ⚙️ Workflow
1. Data replicated across regions
2. Route 53 handles failover
3. Backup region serves traffic
