# Secure File Sharing with S3 and CloudFront

## 📌 Description
Secure file distribution using private S3 bucket and CloudFront with restricted access.

## 🛠 Services Used
- S3
- CloudFront
- IAM
- OAI (Origin Access Identity)

## ⚙️ Workflow
1. Files stored in private S3
2. CloudFront serves content securely
3. Direct S3 access blocked
