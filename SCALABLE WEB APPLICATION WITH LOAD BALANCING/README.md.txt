# Scalable Web Application with Load Balancing

## 📌 Description
Highly available web app using multiple EC2 instances behind a load balancer.

## 🛠 Services Used
- EC2
- ALB (Application Load Balancer)
- Auto Scaling
- VPC

## ⚙️ Workflow
1. Traffic goes to Load Balancer
2. Distributed to EC2 instances
3. Auto Scaling adjusts capacity
