# Serverless Image and Video Processing

## 📌 Description
A serverless system that automatically processes uploaded images and videos using AWS Lambda.

## 🛠 Services Used
- S3
- Lambda
- IAM
- CloudWatch

## ⚙️ Workflow
1. User uploads file to S3
2. S3 triggers Lambda
3. Lambda processes image/video
4. Output stored in another S3 bucket
