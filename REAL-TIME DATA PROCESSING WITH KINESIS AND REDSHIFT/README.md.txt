# Real-Time Data Processing with Kinesis and Redshift

## 📌 Description
Streaming data pipeline that processes real-time data and stores it in Redshift.

## 🛠 Services Used
- Kinesis
- Lambda
- S3
- Redshift

## ⚙️ Workflow
1. Data streamed via Kinesis
2. Lambda processes data
3. Stored in S3 and Redshift
