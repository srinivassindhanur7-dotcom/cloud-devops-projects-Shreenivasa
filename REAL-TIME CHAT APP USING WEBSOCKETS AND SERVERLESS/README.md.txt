# Real-Time Chat Application using WebSockets and Serverless

## 📌 Description
Serverless chat application with real-time messaging.

## 🛠 Services Used
- API Gateway (WebSocket)
- Lambda
- DynamoDB

## ⚙️ Workflow
1. Users connect via WebSocket
2. Messages handled by Lambda
3. Stored in DynamoDB
